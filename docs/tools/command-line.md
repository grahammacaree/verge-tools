# Command Line Image Generator

**Deprecated** — unused; not in the published nav. Source kept under `src/tools/command-line/` for a possible revive.

Places an image under Command Line’s SVG frame and randomized accent boxes.

## Flow

1. Upload image
2. Choose 1:1 or 3:2
3. Boxes/rotation regenerate on load or **Regenerate**
4. Adjust → Finalize → `command-line.jpg`

## Brand notes

- Frame SVGs: `public/images/frames/command-line-1x1.svg`, `command-line-3x2.svg`
- Accent fills: `#d6f31f`, `#5200ff`, `#f9f9f9`
- Box group rotates in 90° steps
