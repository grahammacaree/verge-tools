# Tools

Nav order follows this file. Each `##` heading is the public label; the first line of the body must be `id: <tool-id>`.

## Article Scraper
id: article-scraper

Read a Verge story and output a custom image with headline, authors, etc.

## Decoder Image Generator
id: decoder-image-generator

Quickly convert images to Decoder's main format.

## Installer Image Generator
id: installer-image-generator

Generate an Installer mosaic.

## Verge Filter
id: verge-filter

Takes an uploaded or pasted image and maps the Verge's colors onto it.

## AI Label
id: ai-label

Add an 'AI-generated image' label to AI generated images.
