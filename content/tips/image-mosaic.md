# Image Mosaic

## tip

Work through the steps left to right: layout → images → background → filter → adjust → download.

## wizardTitle

Image Background Generator

## steps.step-1

Choose Layout

## steps.step-2

Select Images

## steps.step-3

Choose Background

## steps.step-4

Choose Filter

## steps.step-5

Adjust Image

## steps.step-6

Download

## notes.step-1

Select an image cell to enable splitting and corner rounding. For single-image compositions, a 3:2 aspect ratio is best.

## notes.step-2

Drag images, or select images and use the upload button.

## notes.step-3

Select a background.

## notes.step-4

Select color filter.

## notes.step-5

Select an image and adjust the slider to zoom in. Click on an unzoomed image to adjust the image center. Pan when zoomed.
